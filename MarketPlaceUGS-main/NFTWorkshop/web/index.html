별빛 페넥여우 NFT 발급 · 쿠폰

Sepolia 전용입니다. NFT 가격은 0 ETH이며 등록·발행·전송에는 가스비가 듭니다. 개인 키 입력은 필요 없습니다.

미연결

1. 관리자: NFT 계약 만들기

수업당 한 번만 배포합니다. 이미 배포했다면 위 계약 주소를 입력하세요.

이 그림은 로컬 미리보기입니다. MetaMask 표시용으로는 같은 PNG를 IPFS 또는 공개 HTTPS 저장소에 올려야 합니다. 127.0.0.1 주소는 다른 사용자의 지갑에서 열 수 없습니다.

기본 방법은 작은 JSON을 계약에 직접 내장합니다. PNG만 공개 주소가 필요합니다. IPFS 주소를 입력하면 메타데이터의 image에는 공개 HTTPS 게이트웨이 주소를 넣어 지갑의 이미지 로딩 호환성을 높입니다. 별도 JSON 업로드는 선택 사항입니다.

발급 후 아래 tokenId를 입력하면 온체인 tokenURI와 공개 image를 다시 검사합니다.

2. 관리자: 학생 쿠폰 등록

등록 완료를 확인한 뒤 쿠폰 전체를 학생에게 전달하세요. 다른 지갑은 이 쿠폰을 사용할 수 없습니다.

3. 학생: 쿠폰 사용

Unity QR 지갑으로 수령하려면 같은 쿠폰을 게임의 NFT 쿠폰 입력 칸에 넣으세요.
